ไฟล์นี้รวบรวมฟังก์ชันทั้งหมดที่ใช้ในการจัดการข้อมูล Wallet โดยตรงกับฐานข้อมูล ผ่าน Prisma Client ซึ่งครอบคลุมการสร้าง, การอ่าน, การอัปเดต, และการดำเนินการที่ซับซ้อน เช่น การยืนยันยอดเงินในธุรกรรม

(async, inner) confirmWalletAmount(transactionVerification, transactionId, amount) → {Promise.<object>}

ฟังก์ชันนี้เป็นกระบวนการสำคัญในการยืนยันธุรกรรมที่รอดำเนินการ (PENDING) โดยจะทำงานภายใน Database Transaction (Atomicity) เพื่อรับประกันว่าการอัปเดตสถานะธุรกรรม และการเพิ่มยอดเงินใน Wallet จะต้องสำเร็จทั้งหมดหรือไม่ก็ล้มเหลวทั้งหมด มีการป้องกันการยืนยันซ้ำซ้อนโดยตรวจสอบสถานะของธุรกรรมก่อนดำเนินการเสมอ
Parameters:
NameTypeDescription
transactionVerificationany(ยังไม่ได้ใช้งานในปัจจุบัน) พารามิเตอร์ที่อาจใช้สำหรับการตรวจสอบเพิ่มเติมในอนาคต
transactionIdstringรหัสเฉพาะ (ID) ของ Transaction ที่ต้องการยืนยัน
amountnumber | stringยอดเงินที่ได้รับการตรวจสอบและยืนยันแล้ว (ต้องเป็นค่าบวก)
Source
  • api/v1/wallets/wallet.service.js, line 24
Throws:
ในกรณีที่ข้อมูล `amount` ไม่ถูกต้อง, ไม่พบ Transaction, หรือ Transaction ไม่อยู่ในสถานะ 'PENDING' ที่สามารถดำเนินการต่อได้
Type
