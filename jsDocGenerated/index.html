เอกสาร API ของระบบ Wallet Backend

เอกสารนี้สร้างขึ้นโดยใช้ JSDoc สำหรับโปรเจกต์ Node.js Backend ของระบบกระเป๋าเงินอิเล็กทรอนิกส์

โครงสร้างของ API แบ่งออกเป็นโมดูลต่างๆ โดยแต่ละโมดูลประกอบด้วย Controller, Route, และ Service ที่เกี่ยวข้อง

โครงสร้างโมดูล API

คลิกที่ชื่อโมดูลเพื่อดูไฟล์เอกสารที่เกี่ยวข้อง รวมถึงคำอธิบายหน้าที่ของแต่ละส่วน:

โมดูลนี้จัดการการทำงานที่เกี่ยวข้องกับผู้ดูแลระบบ รวมถึงการจัดการสิทธิ์ การตรวจสอบ และการควบคุมระบบ

  • Controller: จัดการตรรกะการทำงานของผู้ดูแลระบบ
  • Route: กำหนดเส้นทาง API สำหรับผู้ดูแลระบบ
  • Service: จัดการธุรกิจตรรกะสำหรับผู้ดูแลระบบ

โมดูลนี้จัดการการส่งข้อความประกาศไปยังผู้ใช้ รวมถึงการสร้าง แก้ไข และส่งประกาศ

  • Controller: จัดการตรรกะการส่งข้อความประกาศ
  • Service: จัดการธุรกิจตรรกะสำหรับการประกาศ

โมดูลนี้จัดการงานที่ทำงานตามกำหนดเวลา เช่น การอัปเดตข้อมูลอัตโนมัติ หรือการส่งแจ้งเตือน

  • Controller: จัดการตรรกะงานตามเวลา
  • Route: กำหนดเส้นทาง API สำหรับงานตามเวลา

โมดูลนี้จัดการเป้าหมายทางการเงินของผู้ใช้ รวมถึงการตั้งค่า ติดตาม และบรรลุเป้าหมาย

  • Controller: จัดการตรรกะเป้าหมาย
  • Route: กำหนดเส้นทาง API สำหรับเป้าหมาย
  • Service: จัดการธุรกิจตรรกะสำหรับเป้าหมาย

โมดูลนี้จัดการการอัปโหลด จัดเก็บ และเรียกใช้รูปภาพในระบบ

  • Service: จัดการธุรกิจตรรกะสำหรับรูปภาพ

โมดูลนี้จัดการการเชื่อมต่อและการทำงานกับ LINE API สำหรับการส่งข้อความและการแจ้งเตือน

  • Service: จัดการธุรกิจตรรกะสำหรับไลน์

โมดูลนี้จัดการภารกิจที่ผู้ใช้สามารถเข้าร่วมเพื่อรับรางวัล รวมถึงการสร้างและจัดการภารกิจ

  • Controller: จัดการตรรกะภารกิจ
  • Route: กำหนดเส้นทาง API สำหรับภารกิจ
  • Service: จัดการธุรกิจตรรกะสำหรับภารกิจ

โมดูลนี้จัดการการส่งการแจ้งเตือนไปยังผู้ใช้ รวมถึงการสร้างและจัดการข้อความแจ้งเตือน

  • Controller: จัดการตรรกะการแจ้งเตือน
  • Route: กำหนดเส้นทาง API สำหรับการแจ้งเตือน
  • Service: จัดการธุรกิจตรรกะสำหรับการแจ้งเตือน

โมดูลนี้จัดการสินค้าที่สามารถซื้อได้ในระบบ รวมถึงการจัดการสต็อกและราคา

  • Controller: จัดการตรรกะสินค้า
  • Route: กำหนดเส้นทาง API สำหรับสินค้า
  • Service: จัดการธุรกิจตรรกะสำหรับสินค้า

โมดูลนี้จัดการระบบคิวสำหรับการประมวลผลงานแบบอะซิงโครนัส

  • Service: จัดการธุรกิจตรรกะสำหรับคิว

โมดูลนี้จัดการสลิปการโอนเงิน รวมถึงการอัปโหลดและตรวจสอบสลิป

  • Controller: จัดการตรรกะสลิป
  • Route: กำหนดเส้นทาง API สำหรับสลิป
  • Service: จัดการธุรกิจตรรกะสำหรับสลิป

โมดูลนี้จัดการธุรกรรมทางการเงินทั้งหมด รวมถึงการโอนเงิน การถอน และการฝาก

  • Controller: จัดการตรรกะธุรกรรม
  • Route: กำหนดเส้นทาง API สำหรับธุรกรรม
  • Service: จัดการธุรกิจตรรกะสำหรับธุรกรรม

โมดูลนี้จัดการความสัมพันธ์ระหว่างผู้ใช้และภารกิจ รวมถึงการเข้าร่วมและความคืบหน้า

  • Controller: จัดการตรรกะภารกิจของผู้ใช้
  • Route: กำหนดเส้นทาง API สำหรับภารกิจของผู้ใช้
  • Service: จัดการธุรกิจตรรกะสำหรับภารกิจของผู้ใช้

โมดูลนี้จัดการข้อมูลผู้ใช้ รวมถึงการลงทะเบียน เข้าสู่ระบบ และการจัดการโปรไฟล์

  • Controller: จัดการตรรกะผู้ใช้
  • Route: กำหนดเส้นทาง API สำหรับผู้ใช้
  • Service: จัดการธุรกิจตรรกะสำหรับผู้ใช้

โมดูลนี้จัดการกระเป๋าเงินอิเล็กทรอนิกส์ของผู้ใช้ รวมถึงยอดคงเหลือและประวัติการทำธุรกรรม

  • Controller: จัดการตรรกะกระเป๋าเงิน
  • Route: กำหนดเส้นทาง API สำหรับกระเป๋าเงิน
  • Service: จัดการธุรกิจตรรกะสำหรับกระเป๋าเงิน

ส่วนนี้ประกอบด้วยฟังก์ชันและตัวแปรที่ใช้ร่วมกันในระบบทั้งหมด

  • Global Functions: ฟังก์ชันและตัวแปรทั่วไปของระบบ
